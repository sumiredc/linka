Linka は別のウィンドウで開かれています。

そちらのウィンドウで Linka のサイドパネルを閉じてから、もう一度試してください。

調べた内容をコーディングエージェントに渡す

  1. 単一ファイルのストアを作る 
    relate -d ~/linka/linka.rl < ~/Downloads/linka-export.cypher
  2. 使っているエージェントに MCP サーバーとして登録する 
    claude mcp add linka -- relate serve --database ~/linka/linka.rl --mcp stdio

    登録できたかは claude mcp list で確かめられます。

    ~/.codex/config.toml に追記します（パスは絶対パスで書きます）。

    [mcp_servers.linka]
command = "relate"
args = [
  "serve",
  "--database", "/Users/you/linka/linka.rl",
  "--mcp", "stdio",
]

    Codex を起動し直し、/mcp で linka が表示されれば登録できています。

  3. エージェントに頼む 
    linka のグラフを使って、調べた中でまだ解決策が見つかっていない課題を挙げ、設計でどう扱うべきか提案して
