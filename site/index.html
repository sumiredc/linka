Your research, as a graph, for your coding agent.調べたことをグラフにして、コーディングエージェントへ。

Linka builds a knowledge graph from the pages you read, right in Chrome. Ask it questions, then hand it to your coding agent, such as Claude Code or Codex, over MCP.Linka は、Chrome で読んだページから知識グラフを作ります。グラフに質問でき、MCP で Claude Code や Codex などのコーディングエージェントに渡せます。

Which page answered which concern?どのページが、どの懸念に答えていたか

Before you adopt a technique, you read about it: engineering blog posts, docs, issues and comparisons. One page raises a concern; another proposes a fix. Close the tabs, and those links are gone. Linka keeps them.技術を採用する前に、ブログ・ドキュメント・Issue・比較記事を読み比べます。あるページが懸念を挙げ、別のページが解決策を示す。タブを閉じると、そのつながりは消えてしまいます。Linka はそれを残します。

  1. Clip a pageページをクリップする

    Click the Linka icon. Gemini Nano, Chrome's on-device model, extracts the page's concepts, authors and claims: concerns, solutions, benefits and facts.Linka のアイコンを押すと、Chrome の端末内モデル Gemini Nano が、ページの概念・著者・主張（懸念・解決策・利点・事実）を取り出します。

  2. See the connectionsつながりを見る

    Linka suggests where a solution on one page may address a concern on another, and links pages that share concepts.あるページの解決策が、別のページの懸念に答えていそうな組を、Linka が候補として示します。同じ概念を扱うページどうしもつなぎます。

  3. Ask your graphグラフに質問する

    Ask in plain words, such as “Which solutions address concerns about SQLite?”. Linka shows the Cypher query it ran and highlights the answer in the graph.「SQLite の懸念に答える解決策は？」のように、ふだんの言葉で質問できます。Linka は実行した Cypher クエリを見せ、答えをグラフの上で強調します。

  4. Hand it to your coding agentコーディングエージェントに渡す

    Export the graph and register it as a read-only MCP server with the Relate CLI. Your agent plans with the concerns and solutions you collected. See the steps.グラフを書き出し、Relate CLI で読み取り専用の MCP サーバーとして登録します。エージェントは、あなたが集めた懸念と解決策をもとに計画を立てます。手順（英語）

Private by designデータは端末の外に出ません

Runs on your device端末の中で動く

Extraction and questions run on Gemini Nano in Chrome. Linka calls no external API.抽出も質問も、Chrome の Gemini Nano で動きます。Linka は外部の API を呼びません。

Stored in your browserブラウザの中に保存する

The graph lives in Relate, an embedded graph database, in the extension's private storage.グラフは、組み込みのグラフデータベース Relate に入れ、拡張機能専用の領域に保存します。

No server, no accountサーバーもアカウントも無い

There is no Linka server, no account and no analytics. Linka reads a page only when you clip it.Linka のサーバー・アカウント・解析はありません。ページを読むのは、クリップしたときだけです。

Requirements動作環境

Desktop Chrome with Gemini Nano: Windows 10/11, macOS 13+, Linux or a Chromebook Plus, at least 22 GB of free disk space, and either a GPU with more than 4 GB of VRAM or 16 GB of RAM with 4 or more CPU cores. If the model is not on your device yet, Chrome downloads it the first time you open Linka. English pages work best.Gemini Nano が使えるデスクトップ版の Chrome が要ります。Windows 10/11、macOS 13 以降、Linux、Chromebook Plus のいずれかで、空きディスクが 22 GB 以上あり、VRAM が 4 GB を超える GPU か、16 GB の RAM と 4 コア以上の CPU が必要です。モデルがまだ端末に無ければ、初めて Linka を開いたときに Chrome がダウンロードします。英語のページで最もよく動きます。

Handing the graph to a coding agent needs the Relate CLI.コーディングエージェントに渡すには、Relate CLI が要ります。
