Keeping offline data from disappearing

A local-first app is only as good as its storage. Two things tend to lose data: edits that live only in memory, and storage that the browser evicts when the disk fills up.

Edits in memory

If unsynced edits are kept only in JavaScript memory, closing the tab before the next sync throws them away. Write every edit to durable storage as it happens.

Eviction

By default, an origin's storage is best-effort. Once the user has saved real work, request persistent storage, and show how much of the quota is used so the user is not surprised.

Even persistent storage can be cleared by the user, so offer an export as well.
