Syncing a local-first notes app

A notes app that syncs by sending whole documents and keeping the newest copy uses last-write-wins. When two devices edit the same note offline, one device's changes simply vanish.

Merge instead of overwrite

Model each note as a Yjs document. Persist it to IndexedDB on every change and exchange updates over a WebSocket provider when the device is online, so the app keeps working while the server is unreachable.

Watch the history

CRDT documents remember enough history to merge, so a heavily edited note grows over time.
